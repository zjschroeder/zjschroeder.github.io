# zjschroeder.com

Portfolio site for Zachary J. Schroeder, PhD. Built with [Quarto](https://quarto.org) and published to GitHub Pages by the workflow in `.github/workflows/publish.yml`.

Interactive figures are Observable Plot cells that read small aggregate CSVs in each project folder; no participant text, tweet text, or person-level records are stored in this repository.

Local preview: `quarto preview`.
